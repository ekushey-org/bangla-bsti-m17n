# জাতীয় (Jatiya) m17n ইনপুট মেথড

> জাতীয় কীবোর্ড (সংশোধিত) **BDS 1738:2018** (BSTI)-এর ওপর ভিত্তি করে এবং স্ট্যান্ডার্ড লজিক্যাল ইউনিকোড টাইপিংয়ের উপযোগী করে তৈরী করা লিনাক্স ইনপুট মেথড (`m17n-lib`-এর মাধ্যমে IBus / Fcitx)।

---

## 📌 পরিচিতি (Overview)

এই রিপোজিটরিতে লিনাক্স ডেস্কটপ পরিবেশের জন্য **m17n**-ভিত্তিক `bn-Jatiya.mim` ইনপুট মেথড ফাইলটি সরবরাহ করা হচ্ছে, যা বর্তমান **জাতীয় (Jatiya)** কীবোর্ড লে-আউটকে কার্যকর করে।

বাংলাদেশ স্ট্যান্ডার্ডস অ্যান্ড টেস্টিং ইনস্টিটিউশন (BSTI) প্রকাশিত অফিশিয়াল ডেস্কটপ মানদণ্ডে (**BDS 1738:2018**) পুরোনো টাইপরাইটার ধারার টাইপিং অভ্যাস (যেমন: বিজয়ের মতো প্রি-ইউনিকোড ভিজ্যুয়াল ইনপুট) অনুসরণ করা হয়েছে। এই ইনপুট মেথডটিতে স্ট্যান্ডার্ড কী-অ্যাসাইনমেন্ট, স্বয়ংসম্পূর্ণ ডেড-কী সমন্বয় এবং AltGr শর্টকাট অক্ষুণ্ণ রেখে সম্পূর্ণরূপে **ইউনিকোড লজিক্যাল সিকোয়েন্স** (Logical Ordering) নিশ্চিত করা হয়েছে।

## 🚀 ব্যবহারিক সুবিধা ও উন্নয়নসমূহ (Key Usability Enhancements)

### ১. ভিজ্যুয়াল অভ্যাসের বিপরীতে যৌক্তিক ইউনিকোড ইনপুট
ঐতিহ্যবাহী মেকানিক্যাল টাইপরাইটার এবং প্রি-ইউনিকোড ভিজ্যুয়াল লে-আউটে (যেমন: বিজয়) বর্ণের ব্যাকরণগত বা উচ্চারণের লজিক্যাল ক্রমের পরিবর্তে পর্দার দৃশ্যমান রূপ দেখে টাইপ করতে হতো:
* **পুরোনো ভিজ্যুয়াল পদ্ধতি (বিজয় / টাইপরাইটার):** `ে` + `ক` + `া` = `কো` অথবা `ে` + `ক` + `ৗ` = `কৌ` (**দৃশ্যমান উপস্থাপনা**)
* **ইউনিকোড লজিক্যাল পদ্ধতি:** `ক` + `ো` = `কো` অথবা `ক` + `ৌ` = `কৌ` (**ব্যঞ্জনবর্ণ + কার-চিহ্ন**)

**Jatiya m17n**-এ টাইপিং কঠোরভাবে আন্তর্জাতিক ইউনিকোড নীতি মেনে চলে। আপনি স্বাভাবিক উচ্চারণ ও কোডিং ক্রমানুযায়ী সরাসরি টাইপ করতে পারবেন।

### ২. স্বয়ংসম্পূর্ণ ডেড-কী ব্যবস্থা (`g` হসন্ত / Virama হিসেবে)
BDS 1738:2018 মানদণ্ড অনুযায়ী:
* `g` চাপলে তা ডেড-কী হিসেবে হসন্ত (`্`) আউটপুট আসবে।
* `g` চাপার পরপরই সংশ্লিষ্ট কার-চিহ্ন টাইপ করলে তা সরাসরি পূর্ণাঙ্গ স্বাধীন স্বরবর্ণে রূপান্তরিত হয় (যেমন: `g` + `f` = `আ`, `g` + `d` = `ই`, `g` + `c` = `এ`)।
* এককভাবে সাধারণ হসন্ত ব্যবহারের জন্য বিকল্প হিসেবে `AltGr + g` (বা `Alt + g` / `Ctrl + Alt + g`) ব্যবহার করা যায়।

### ৩. দ্রুত যুক্তাক্ষর ইনপুটের জন্য AltGr শর্টকাট
বারবার হসন্ত দিয়ে বর্ণ ভেঙে লেখার ঝামেলা কমাতে বহুল ব্যবহৃত জটিল যুক্তাক্ষরগুলো `AltGr` (বা `Alt` / `Ctrl+Alt`) চেপে সরাসরি এক প্রেসে টাইপ করা যায়:
* `AltGr + q` ➔ **ঙ্ক**
* `AltGr + y` ➔ **ঞ্চ**
* `AltGr + u` ➔ **ঞ্জ**
* `AltGr + i` ➔ **জ্ঞ**
* `AltGr + o` ➔ **ঙ্গ**
* `AltGr + j` ➔ **ক্ষ**
* `AltGr + v` ➔ **ব়্য**
* `AltGr + b` ➔ **ঞ্চ**
* `AltGr + n` ➔ **ষ্ণ**
* `AltGr + m` ➔ **হ্ম**

## 🛠️ লিনাক্সে ইনস্টলেশন নির্দেশিকা

### প্রয়োজনীয় প্যাকেজ (Prerequisites)
আপনার ডিস্ট্রিবিউশনে `m17n-db`, `m17n-lib` এবং আপনার পছন্দসই ইনপুট ফ্রেমওয়ার্ক (`ibus-m17n` অথবা `fcitx5-m17n` / `fcitx-m17n`) ইনস্টল করা থাকতে হবে:

#### Debian / Ubuntu / Linux Mint
```bash
sudo apt update
sudo apt install m17n-db libm17n-0 ibus-m17n
```

#### RHEL / Rocky Linux / AlmaLinux / CentOS Stream
প্রয়োজনে EPEL রিপোজিটরি সক্রিয় করুন, তারপর ইনস্টল করুন:
```bash
sudo dnf install epel-release
sudo dnf install m17n-db m17n-lib ibus-m17n
```

#### Fedora
```bash
sudo dnf install m17n-db m17n-lib ibus-m17n
```

#### Arch Linux / Manjaro
```bash
sudo pacman -S m17n-db m17n-lib ibus-m17n
```

### ধাপে ধাপে সেটআপ

১. **রিপোজিটরিটি ক্লোন করুন:**
   ```bash
   git clone [https://github.com/ekushey-org/bangla-bsti-m17n.git](https://github.com/ekushey-org/bangla-bsti-m17n.git)
   cd bangla-bsti-m17n
   ```

২. **ম্যাপ ফাইলটি আপনার লোকাল বা সিস্টেম m17n ডিরেক্টরিতে কপি করুন:**
   * *কেবল বর্তমান ব্যবহারকারীর জন্য (না বুঝলে এটাই ব্যবহার করুন):*
     ```bash
     mkdir -p ~/.m17n.d
     cp bn-Jatiya.mim ~/.m17n.d/
     ```
   * *সিস্টেম-ওয়াইড (সকল ব্যবহারকারীর জন্য):*
     ```bash
     sudo cp bn-Jatiya.mim /usr/share/m17n/
     ```

৩. **ইনপুট ফ্রেমওয়ার্ক রিস্টার্ট করুন:**
   * *IBus ব্যবহারকারীদের জন্য:*
     ```bash
     ibus restart
     ```
   * *Fcitx5 ব্যবহারকারীদের জন্য:*
     ```bash
     fcitx5 -r
     ```

৪. **ইনপুট মেথড যুক্ত করুন:**
   * আপনার ডেস্কটপ সেটিংস (GNOME / KDE / XFCE) অথবা IBus / Fcitx কনফিগারেশন উইন্ডো ওপেন করুন।
   * **Input Methods** বা **Keyboard Settings**-এ যান।
   * **Bengali** ➔ **Jatiya (m17n)** নির্বাচন করে যুক্ত করুন।

## ⚙️ ডেডিকেটেড AltGr কি কনফিগারেশন

সাধারণ ইউএস কোয়ার্টি (US QWERTY) কীবোর্ডে ডানপাশের Alt কি-টি সাধারণ `Alt` হিসেবে কাজ করে, যার ফলে ৩য় স্তরের যুক্তাক্ষর টাইপ করতে দুটি আঙুল ব্যবহার করে `Ctrl + Alt` চাপতে হয়। আপনার কীবোর্ডের ডানপাশের Alt কি-কে একক ক্লিকে **AltGr** হিসেবে ব্যবহার করতে নিচের সেটিংস প্রয়োগ করুন:

### GNOME (Ubuntu, Fedora, Debian, RHEL)
১. সিস্টেমে **GNOME Tweaks** ইনস্টল না থাকলে ইনস্টল করে নিন:
   ```bash
   sudo apt install gnome-tweaks       # Debian / Ubuntu
   sudo dnf install gnome-tweaks       # Fedora / RHEL / Alma / Rocky
   ```
২. **GNOME Tweaks** ওপেন করে **Keyboard & Mouse** ➔ **Additional Layout Options**-এ যান।
৩. **Key to choose the 3rd level** অপশনটি প্রসারিত করুন।
৪. তালিকা থেকে **Right Alt** টিক দিন।

বিকল্পভাবে, টার্মিনালে নিচের GSettings কমান্ডটি চালিয়ে সরাসরি সক্রিয় করতে পারেন:
```bash
gsettings set org.gnome.desktop.input-sources xkb-options "['lv3:ralt_switch']"
```

### KDE Plasma
১. **System Settings** ➔ **Input Devices** ➔ **Keyboard**-এ যান।
২. **Advanced** ট্যাবে ক্লিক করুন।
৩. **Key to choose the 3rd level** প্রসারিত করুন।
৪. **Right Alt** নির্বাচন করে **Apply** বাটনে ক্লিক করুন।

### XFCE / MATE / অন্যান্য হালকা ডেস্কটপ
১. **Keyboard Settings** ➔ **Layout** ট্যাবে যান।
২. **Key to choose the 3rd level** ড্রপডাউন মেনু থেকে **Right Alt** নির্বাচন করুন।

### X11 সেশনে তাৎক্ষণিক চালু করার নিয়ম (`setxkbmap`)
বর্তমান X11 সেশনে তাৎক্ষণিকভাবে Right Alt-কে AltGr হিসেবে কার্যকর করতে:
```bash
setxkbmap -option lv3:ralt_switch
```
*(রিবুটের পরেও এই সেটিংস স্থায়ী রাখতে আপনার `~/.xprofile` বা `~/.xinitrc` ফাইলে `setxkbmap -option lv3:ralt_switch` লাইনটি যুক্ত করে দিন।)*
